# 暗黑数据可视化短视频制作

## 这是什么风格

深黑色背景，橙红色光晕和粒子漂浮，文字一个字一个打出来，数字从 0 滚动到目标值，配合圆环仪表、脑区点阵、曲线交叉图、柱状图等"信息图"动效。整体像一份"深夜版数据报告"，专治各种"你以为……其实……"的认知反差科普选题（熬夜、短视频、拖延、信息茧房、噪音、久坐等）。

典型结构（16:9 横屏 1920×1080，30fps。**整片控制在 60 秒左右**，别为了"讲透"而拉长）：

```
00 钩子开场（场景化画面，如手机时钟跳动）
01 认知反差（"你以为……其实……"）
02 N 宫格速览（把全片要点一次给全，相当于标题前的"预告片"）
03 大标题揭示（配一次闪色转场）
04-09 逐章拆解（每章：左图右文 或 左文右图，配一句数据来源）
10 结尾升华句 + 3 条行动建议 + CTA
```

**不要跳过调研直接套模板**——这个风格的说服力来自"每一页都有数据出处"，没有可信数据支撑的页面看起来会很假。

## 工作流程（6 步）

### 第 1 步：确定选题与核心反差

用一句话写出"认知反差"：用户以为是 A，其实是 B。例如：
- "只是晚睡一会儿" → "正在同时损伤 7 个身体系统"
- "只是刷了几个视频" → "正在重塑你的大脑奖赏回路"

这句话会直接变成片头字幕，是整条片子的脊梁。

### 第 2 步：调研，找到 6-8 条可引用的真实数据

**这一步不能编数据。** 每一章配一条真实可查的数字或结论，并标注出处（机构/论文/年份/样本量）。用 `web_search` / `web_fetch` 检索，优先找：
- 权威机构年度报告（如行业白皮书、政府统计公告）
- 同行评议论文或可信的科普媒体对论文的转述（标注作者+期刊+年份+样本量）
- 若数据有争议或是相关性而非因果性，**必须**在画面上注明"相关 ≠ 因果"或类似限定语，这既是科学诚实也能降低被平台判定夸大的风险

把 6-8 条数据整理成表格：`章节序号 | 一句话钩子 | 核心数字 | 可视化方式建议 | 来源`。可视化方式建议从 `references/scene-cookbook.md` 里挑（圆环仪表/点阵脑区/双曲线交叉/柱状图/漂移游走/日历计时器……每种对应一类数据：占比→圆环，趋势→曲线，对比→柱状图或双轴交叉，概率/成瘾感→点阵或老虎机意象）。

### 第 3 步：写分镜时间表（不要边写代码边想节奏）

把 6-8 个章节放进一个时间轴。**每章时长 = 该章动画走完的时间 + 0.8 秒落点**，一秒都不多留（详见本节末尾「场景时长怎么定」）。先写这张表，再动手写代码，否则很容易节奏凌乱：

| 时间段(s) | 场景函数 | 内容要点 |
|---|---|---|
| 0.0-3.1 | s_hook | 钩子画面，一句话立住 |
| 3.1-6.2 | s_think | 认知反差（"你以为……其实……"） |
| 6.2-9.35 | s_grid | N 宫格速览，一次给全 |
| 9.35-12.85 | s_title | 大标题揭示（配一次闪色转场） |
| 12.85-... | s_ch1 ... s_chN | 逐章拆解，**每章 4.6-7.5 秒**（= 动画走完 + 0.8 秒） |
| 最后 6-8s | s_outro | 升华句 + 3条建议 + CTA |

**开场不要堆转场页。** 扫光分隔（s_line）和"N 个系统"（s_systems）属于"纯转场、无新信息"的页面，
在 100 秒以内的片子里应当直接删掉，能省 6-9 秒；只有 120 秒以上的长片才值得保留做节奏呼吸。

#### 场景时长怎么定：动画走完 + 0.8 秒

**这是本 Skill 最容易做错、也最伤观感的一条。**

很多人（包括之前的本 Skill）会把每章排成 10-20 秒，但场景里的动画 —— 文字淡入、数字滚动、
图形生长 —— **统统在 4-5 秒内就走完了**。剩下的十几秒，是在原地停着等观众看完。
观众早就读完了，画面还在那里，观感就是"慢"。

正确算法只有三步：

1. 看该章场景函数里**最后一个** `ap()` / `ramp()` 的时间点，加上它的时长
   —— 这就是"所有元素都出现完"的时刻；
2. **再加 0.8 秒**作为落点，让最后一句在画面上站住；
3. 算出来的数就是该章时长。**一秒都不要多。**

各章时长因此**天然不同**（参考示例：4.6 / 4.9 / 5.1 / 6.8 / 6.0 / 5.5 秒），
这是内容量差异的正常体现，不要为了"整齐"把它们拉平。

| 该章信息量 | 通常时长 | 例 |
|---|---|---|
| 3-4 行文字 + 一个图形 | 4.5-5.5 秒 | 单条法条 + 一个期限数字 |
| 5-6 行文字 + 图形生长动画 | 5.5-6.5 秒 | 柱状图 / 圆环 + 一句结论 |
| 7 行以上文字 / 多条并列要点 | 6.5-7.5 秒 | 三条认定规则 + 举证提示 |

**成片总长参考：6 章 + 开场 + 结尾 ≈ 55 秒。** 整片控制在 60 秒内是这类内容号的常态。
如果嫌内容多放不下，**删内容，别加时长** —— 信息密度才是完播率的朋友。

场景切换的淡入淡出也相应收紧到 0.25 秒（原来 0.35-0.45 秒在 5 秒的场景里太占比例）。

详细的节奏公式（淡入淡出时长、文字打字机速度、数字滚动曲线）见 `references/visual-spec.md`。

### 第 4 步：搭建环境（务必先做这步，国产大模型在 Linux 容器里最常栽在这）

```bash
# 1. 确认 ffmpeg 可用
ffmpeg -version || echo "需要安装 ffmpeg：apt-get install -y ffmpeg 或 brew install ffmpeg"

# 2. 确认 Python 依赖
python3 -c "import PIL, numpy" || pip3 install pillow numpy

# 3. 跑字体探测脚本——这是全流程唯一会因平台不同而失败的环节
python3 scripts/font_finder.py
```

`scripts/font_finder.py` 会按 macOS → Linux（Noto Sans CJK / 文泉驿 / 思源黑体）→ Windows（微软雅黑）的顺序探测中文字体，找不到会打印具体的安装命令（例如 Linux 下 `apt-get install -y fonts-noto-cjk` 或 `fc-list` 核对字体名）。**不要跳过这一步直接假设字体路径存在**——这是本 Skill 在跨平台/跨模型场景下最大的失败点。确认脚本输出 `✅ 字体就绪` 后再继续。`engine.py` 启动时会自动按 `DARK_FONT` 环境变量 → `font_finder.py` 探测 → 常见路径的顺序选字体，不需要手动改代码；想指定字体就 `export DARK_FONT=/path/to/font.ttc`（ttc 可写 `路径#序号`），数字字体可用 `DARK_NUM_FONT`。

### 第 5 步：实现场景代码

1. 复制 `scripts/engine.py` 到项目目录，它是通用渲染引擎（文字排版、发光、缓动函数、背景光晕、章节进度条、封面生成、并行分段渲染命令行），**不要修改这个文件本身**，除非要扩展通用能力。
2. 复制 `scripts/example_scenes.py` 作为起点，这是一个可运行的参考示例（"睡眠剥夺"选题，3 个章节的完整实现），展示了如何从 engine 里导入工具函数、如何写一个场景函数、如何组装 `SCENES` 时间轴列表。
3. 参照 `references/scene-cookbook.md` 里的部件食谱（圆环仪表 / 点阵脑区 / 双曲线交叉 / 柱状图 / 漂移游走 / 日历计时器 / 标题揭示 / 结尾卡），为每个章节选 1-2 个部件组合，写成形如 `def s_ch1(u): ...` 的函数（`u` = 该场景开始后经过的秒数）。
4. 把所有场景函数和它们的起止时间、光晕参数、淡入淡出时长，组装进 `SCENES` 列表（`example_scenes.py` 里有完整示例）。

**自查清单**（每章都要过一遍）：
- [ ] 画面上有可读的数据来源一行小字（参照 `source()` 函数）
- [ ] 核心数字用大号数字字体，并且是从 0 动画滚动到目标值，不是瞬间出现
- [ ] 文字不超过 2 行，单行不超过 14 个汉字（1920 宽屏幕，字号 40+ 时的经验值）
- [ ] 相关性数据标注了"相关 ≠ 因果"

### 第 6 步：渲染、合成、质检、交付

```bash
# 1. 先渲染几张关键时间点的静帧拼图自查版式和字号（不要直接渲染全片，省时间）
python3 engine.py still <输出目录> 4 9.5 20 45 80 120 145

# 2. 自查无误后，并行渲染分段（按 CPU 核数切片，九段起步）
#    参考 example_scenes.py 底部的并行渲染命令模板

# 3. 用 ffmpeg concat 拼接分段 + 封面 + 配乐
#    封面必须放在视频最前面第 0-2 帧（约 0.1 秒），抖音默认取首帧做封面
#    配乐：用 scripts/music_gen_v2.py 生成原创氛围音（中频和声垫+旋律+鼓点+转场音效），
#    绝不能直接盗用参考视频的原声。这类片子大多没有旁白，配乐是唯一的声源，
#    务必用 v2 中频版——v1(music_gen.py) 的能量压在 40–165Hz，手机外放等于没声音，
#    详见下面「两个高频翻车点」第一节

# 4. 质检：抽查首帧、0.12秒处帧、中段几帧、尾帧；核对总帧数=分段帧数之和；核对分辨率/码率
ffprobe -v error -show_entries stream=width,height,r_frame_rate,bit_rate -show_entries format=duration -of compact 成片.mp4
```

**交付清单**（照着这份清单检查，缺一项都不算完成）：
- [ ] 成片 mp4（1920×1080 或按需求的其他分辨率，30fps，码率 ≥ 4 Mbps 保证文字边缘清晰）
- [ ] 封面图（横版 16:9 + 竖版 3:4，已内嵌为视频前 0.1 秒）
- [ ] 若平台主推 3:4 封面：横屏首帧内嵌 810×1080 竖版封面安全区 + 单独导出 1080×1440 竖版封面 PNG
- [ ] 每条数据标注来源（可单独导出一份"数据来源清单.md"方便过审核）
- [ ] 一版"发布文案"：标题（主推+2备选）、简介、标签

## 两个高频翻车点（务必看）

### 一、配乐：验收标准是"手机外放"，不是耳机

这类视频通常没有旁白，**配乐是唯一的声源**。但不能只看整体电平——纯低频的"氛围垫"在耳机里听得见，
在手机/笔记本外放上约等于没有声音（手机扬声器基本推不出 400Hz 以下）。

自检命令（用高通 400Hz 模拟手机小喇叭，mean 低于 −35dB 就是听不见）：

```bash
ffmpeg -i 成片.mp4 -af "highpass=f=400,volumedetect" -f null -
```

- **用 `scripts/music_gen_v2.py`（中频版）**：和声垫铺在 175–440Hz 并叠 2/3 次泛音，
  另有中频旋律线（A4–G5）与每拍 hi-hat 提供节奏存在感，底鼓补中频击打成分。
- 输出端用 `tanh` 软限幅抬高平均电平，峰值留 −2dB 余量给 AAC 编码。
- 换配乐**不必重渲染视频**（秒级完成）：

  ```bash
  ffmpeg -i 旧成片.mp4 -i 新配乐.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k -shortest 新成片.mp4
  ```

实测对照（同一选题）：v1 中频段只有 −43.3dB（外放等于静音）→ v2 −28.2dB，**提升约 15dB、5.8 倍声压**。

### 二、封面：横屏视频怎么给平台提供 3:4 竖版封面

抖音/视频号主推 3:4 封面。**视频保持 1920×1080 横屏不变**，把首帧设计成
"画布正中央 810×1080 正好是一张完整竖版封面"，左右两侧用背景光晕自然延展（不要留死黑）。
平台按 3:4 裁切首帧时，裁到的就是这个封面：

- 裁切参数：`crop=810:1080:555:0`
- 实现方式：写一个 `_cover_block(cx, w, h)`，以 **810×1080（正好 3:4）为设计基准**，
  字号按 `w/810` 缩放、纵向坐标按 `h/1080` 缩放——同一份代码既能画纯 3:4 封面（1080×1440），
  也能画横屏画布里居中的 3:4 安全区（810×1080），不用写两套布局。
- 同时单独导出一张 1080×1440 纯竖版封面备用（平台支持手动上传封面时用这张）。
- 封面文字控制在"胶囊标签 / 大标题 / 副标题 / 关键词"≤4 组，数据卡片文案 ≤4 字，避免堆砌。
- **换首帧不必重渲染全片**：只重跑包含封面的那一段（如 `seg 0 600`），再 `concat -c:v copy` 即可。

## 排错速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 中文显示成方块/问号 | 没找到中文字体 | 重新跑 `font_finder.py`，按提示装字体包 |
| 字渲染出来很细/很粗不对 | ttc 索引或字重文件选错 | 查 `references/visual-spec.md` 字体角色映射表，用 `fc-list :lang=zh family style` 核对实际字重名 |
| 渲染卡在很慢 | 没有并行分段渲染 | 按 CPU 核数拆分时间轴并行跑，再 concat |
| 视频时长和分镜表对不上 | 总帧数算错 | 总帧数 = 封面帧数(3) + 正文秒数×30，渲染前用 `ffprobe -count_frames` 核对 |
| 画面太暗/太糊 | 分辨率没问题但字号/线宽太小 | 字号按 1920 宽屏幕设计：正文 40-56，大数字 200-350，不要照抄 1280 宽的尺寸 |
| 想换配色（比如公司品牌是红色不是橙色） | 本风格默认橙红 `(255,90,40)`，可直接替换成品牌红 | 只改 `engine.py` 里的 `ORG` 常量一处即可全局生效 |
| 背景音乐"外放听不见" | 配乐能量压在低频，手机扬声器推不动 400Hz 以下 | 改用 `music_gen_v2.py`；自检 `ffmpeg -i x.mp4 -af "highpass=f=400,volumedetect" -f null -`，mean 低于 −35dB 就是听不见 |
| 数字后面的 % 渲染成方框 | 全角「％」(U+FF05) 在西文数字字体（Avenir 等）里缺字形 | 凡是用 `num`/`numd` 渲染的数字，百分号一律写半角 `%`；只有中文行（PingFang）才可用全角 |
| 汉字变成方框/豆腐块 | 用 `num`/`numd`（西文数字字体）渲染了中文 | **数字字体里只放数字和半角符号**，任何汉字都要用 `reg`/`med`/`semi`（PingFang）。例：`S('1','numd',250) + S(' 年','semi',140)`，别写成 `S('1 年','numd',250)` |
| 柱状图数值和轴标签叠在一起 | 轴单位标签放在了柱子上方 | 轴单位标签一律放基线下方左侧（如 x=150, y=900），别放柱顶区域 |
| 示意图的分段标注位置不对 | 标注 x 写死了 | 按色块中心动态算：`(段起点 + 段终点) / 2` |
| 封面被平台裁掉文字 | 横屏首帧没留 3:4 安全区 | 按「横屏内嵌 3:4 封面」方案重做首帧，裁切参数 `crop=810:1080:555:0` |
| zsh 下 `rm -f dir/*.mp4` 报 "no matches found" 并中断整条命令链 | zsh 的 nomatch 选项：没有匹配文件时直接报错 | 用 `rm -f dir/*.mp4(N)`，或干脆去掉这步删除 |

## 参考文件

- `references/visual-spec.md` —— 精确的配色色值、字号字重映射表、间距网格、缓动公式、章节进度条规则、封面规格。写代码前先看这个。
- `references/scene-cookbook.md` —— 10 种可复用部件的代码片段（圆环仪表/点阵脑区/双曲线交叉/柱状图/漂移游走/日历闪烁/网格宫格/标题揭示/章节HUD/结尾卡），每章拆解页基本是这些部件的排列组合。
- `scripts/engine.py` —— 核心渲染引擎，封装文字富文本渲染、发光效果、缓动函数、背景光晕生成、章节进度条、封面生成、**场景交叉淡化合成 `render_crossfade()`**、CLI（still / cover / seg / frames 四种模式）。
- `scripts/font_finder.py` —— 跨平台中文字体探测工具，独立可运行，`engine.py` 会自动调用它选字体。
- `scripts/preflight.py` —— **交付前自检脚本**。一次查完分辨率 / 码率 / 时长 / 峰值 / **手机外放可闻性** / 首帧封面是否正常，
  用法 `python3 preflight.py 成片.mp4 --min 48 --max 62`，全通过才算交付。
- `references/topic-library.md` —— **选题库**。三条准入标准、四个方向的选题池（含每个选题的数据源）、数据源优先级、
  以及绝对不能碰的红线选题。
- `scripts/music_gen.py` —— 早期版本，纯低频"氛围垫"（鼓点+低频铺底）。**仅适合戴耳机看**，手机外放基本听不见，新项目请直接用 v2。
- `scripts/music_gen_v2.py` —— **推荐使用**：面向手机外放的中频版配乐生成器（和声垫 175–440Hz 叠泛音 + 中频旋律 + hi-hat + tanh 软限幅）。无旁白的视频请务必用这个。
- `scripts/example_scenes.py` —— 完整可运行的参考答案（"睡眠剥夺"选题，3 章 / 58 秒）。它示范了当前推荐的全部做法：紧凑节奏（开场 14.2 秒、每章按内容量 8.5-12.5 秒）、横屏首帧内嵌 3:4 封面（含 `_cover_block` 写法与裁切参数）、中频配乐命令。照着改选题和数据即可出片。
