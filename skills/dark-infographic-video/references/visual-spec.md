# 视觉规范表

写场景代码前先把这份表格过一遍，照着数值来，不要凭感觉估。所有数值以 1920×1080 画布为基准，
竖屏 1080×1920 可整体套用（横向坐标按比例换算，字号不变，因为竖屏单列文字更窄，正好）。

## 配色

| 用途 | 色值 (RGB) | 说明 |
|---|---|---|
| 背景底色 | `(11, 12, 15)` | 接近纯黑但不是纯黑，留一点灰避免死黑 |
| 主文字 | `(242, 238, 230)` | 微暖白，不用纯白 `#FFFFFF`，纯白在深色背景上太刺眼 |
| 强调色 | `(255, 90, 40)` | 默认暗黑橙。换品牌色时只改 `engine.py` 里的 `ORG` 一处 |
| 次要文字 | `(128, 131, 138)` | 说明性文字、小标题 |
| 分割线/弱化 | `(78, 81, 88)` | 虚线、未激活状态 |
| 数据来源文字 | `(105, 108, 116)` | 比次要文字再暗一点，角落小字 |

背景不是纯色块，而是 1-2 个柔光光晕叠加（见 `BG()` 函数），光晕颜色通常用强调色，强度 0.08-0.26，半径 400-720px。每个场景的光晕位置建议对准该场景视觉重心（比如左侧有个圆环仪表，光晕中心就放在圆环附近）。

## 字号与字重映射（1920 宽屏幕基准）

| 角色 | 字重 key | 字号范围 | 用途举例 |
|---|---|---|---|
| 大标题主字 | `semi` | 280-340 | 片名揭示页，如"短视频"两个字 |
| 核心大数字 | `num` / `numd` | 200-400 | "47秒"、"156分钟"、"40天" 这类冲击力数字 |
| 章节标题 | `semi` | 56-100 | 每章的核心结论句，如"想停，停不下来。" |
| 正文说明句 | `reg` / `med` | 38-52 | 铺垫句、过渡句 |
| 小标签/编号 | `numd` | 22-36 | 章节编号 01-07、百分比标注 |
| 数据来源角标 | `reg` | 22 | 画面左下角一行小字 |
| 封面大标题 | `semi` | 短标题(2-4字)用 280-330；长标题酌情降到 200 |

**字号太小是最常见的翻车点**——1920 宽的画面上，正文字号低于 36 在手机上会糊成一团。宁可让一页信息少一点，也不要为了塞下更多字而缩小字号。

## 版式网格

- 安全边距：左右各留 ≥ 60px，顶部 HUD 预留 60-100px，底部 HUD/来源角标预留 100px。
- 左图右文 / 左文右图两栏布局：图形中心大约在 x=450-520，文字区从 x=760-980 起步，这样两栏不会挤在一起。
- 单行文字控制在 14 个汉字以内（字号 50+ 时）；超过就主动换行，不要指望自动换行。
- 每章结构尽量统一："一句铺垫（小字）→ 一句冲击结论（大字，可拆两行用强调色标重点词）→ 一个核心数字或图形 → 一句解释 → 一行数据来源"，这个节奏是整个风格"有说服力"的关键，不要为了花哨打乱它。

## 缓动函数与节奏公式

| 函数 | 用途 | 典型参数 |
|---|---|---|
| `ramp(u, t0, d)` | 线性从 0 到 1 | d=0.3-0.8s 常规淡入 |
| `eo(x)` ease-out | 文字/元素淡入+上浮，先快后慢 | 配合 `ap(u, t0, d)` 使用 |
| `eio(x)` ease-in-out | 数字滚动、线条生长、进度条填充 | 先慢后快再慢，更"有重量感" |

**标准淡入上浮**：`ap(u, t0, d=0.6)` 返回 `(alpha, y偏移)`，y偏移从 18-28px 衰减到 0。几乎所有文字出场都用这个，不要用瞬间出现。

**打字机效果**：用 `T(segs, x, y, p=ramp(u, t0, 持续时长))`，`p` 从 0 到 1 时文字逐字出现。持续时长按文字长度估算，大约每字 0.05-0.08 秒，一整句 10 字左右用 0.6-1.1 秒。

**数字滚动**：目标值乘以 `eio(ramp(u, t0, 持续时长))`，持续时长 2-2.5 秒比较有分量感，太快（<1秒）会显得随意，太慢（>3秒）会显得拖沓。公式示例：
```python
val = int(round(156 * eio(ramp(u, 0.8, 2.2))))
```

**场景整体淡入淡出**：每个场景在 `SCENES` 列表里配置 `(淡入时长, 淡出时长)`，常规场景 0.35-0.45s 双向；揭示型场景（标题页）可以用 `post.append(('fill', color, alpha))` 做全屏闪白/闪色转场增强冲击感，只在标题揭示和开场结尾这种关键节点用，用多了会廉价。

## 章节进度条规则（HUD）

- 顶部左上角：当前章节编号(2位数字, 强调色) + 章节名(白, semi) + 副标题(灰, reg)，格式 `01 —— 注意力 · 被切碎的专注`
- 底部：N等分横条，整条片子章节数(N)固定，每段显示编号+名称，已完成章节的分隔线变橙，当前章节的分隔线从左到右动态填充（按该章节进度百分比）
- 只在"正文拆解阶段"显示（开场钩子、标题揭示、结尾升华不显示），用 `fade_in`/`fade_out` 参数控制整体出现/消失时机

## 数据来源角标规则

**每一个带具体数字的章节都必须有一行来源小字**，格式建议：
```
作者/机构, 期刊/报告名, 年份 · 关键限定词(样本量/置信区间/"相关≠因果"等)
```
位置固定在画面左下角 (x=60, y=978)，颜色用最暗的 `(105,108,116)`，字号 22-26，不需要动画，场景淡入后常驻即可。

## 封面规格

| 规格 | 尺寸 | 用途 |
|---|---|---|
| 横版 | 1920×1080 | 视频内嵌封面帧（前 0.1 秒），部分平台横屏列表展示 |
| 竖版 | 1080×1440 (3:4) | 抖音手动选择封面时上传 |

封面结构（从上到下）：胶囊标签（如"7个系统·深度拆解"）→ 大标题（强调色高亮关键词，带发光）→ 分隔线 → 副标题（提炼核心反差句）→ 关键词小字（用间隔号分隔 3-5 个关键词）。竖版可在底部额外加 1-2 个核心数据小卡片。封面文字总量要比正文页更克制——封面只放"钩子级"的信息，不要堆砌。

## 视频技术规格

| 项目 | 推荐值 | 说明 |
|---|---|---|
| 分辨率 | 1920×1080（横屏）或 1080×1920（竖屏） | 不要低于 1080P，720P 在手机全屏观看时文字边缘会发糊 |
| 帧率 | 30fps | 够用，60fps 对这种图形动效类视频收益不明显，文件却翻倍 |
| 码率 | ≥ 4 Mbps（用 `-crf 12 -preset slow` 这类高质量 CRF 编码） | 深色背景+大量文字边缘，码率不够会出现色带和文字毛边 |
| 封面帧数 | 3 帧 @30fps ≈ 0.1 秒 | 对应"压在第 0-0.1 帧"的需求 |
| 总时长 | **55-60 秒**（6 章） | **场景时长 = 该章动画走完的时间 + 0.8 秒落点**。动画基本都在 4-5 秒内走完，每章实际只需 4.6-7.5 秒。按 15-20 秒一章排是最常见的错误——多出来的十几秒全是"等观众看完"的空转 |
