# 选题库：什么样的题目适合这个风格

## 三条准入标准

一个选题能不能做，只看这三条。**三条都满足才开做。**

1. **有认知反差** —— 必须是"你以为 A，其实 B"的结构。
   - ✅ 久坐的危害（你以为坐着最省力，其实代谢在停摆）
   - ❌ 跑步的好处（这是"你以为 A，其实 A"，没有反差，做出来会平）

2. **有可查的权威数据** —— 每一章至少有一条能标注出处的数字。
   找不到数据的选题，硬做出来一眼就假。

3. **没有合规风险** —— 见文末「红线」。

缺第一条，片子会平；缺第二条，片子会假；缺第三条，片子会挂。

## 可用选题池

### A. 身体 / 健康（数据源最充足，最好做）

| 选题 | 核心反差 | 数据源 |
|---|---|---|
| 熬夜的危害 | 只是晚睡一点 → 六个系统同时在受损 | 中国睡眠研究会白皮书、WHO/IARC、欧洲心脏杂志 |
| 久坐的危害 | 坐着最省力 → 代谢和循环在停摆 | WHO 身体活动指南、《柳叶刀》久坐研究 |
| 外卖的危害 | 省下时间 → 高油高盐的慢性账 | 中国居民膳食指南、中国疾控中心营养调查 |
| 用眼过度的危害 | 只是眼睛累 → 视网膜损伤不可逆 | 国家卫健委近视率数据、眼科临床研究 |
| 长期缺水的危害 | 不渴就不用喝 → 认知能力先下降 | 运动医学与营养学期刊脱水实验 |
| 不吃早餐的危害 | 少吃一顿更健康 → 胆结石与代谢紊乱 | 营养学期刊队列研究 |

### B. 注意力 / 认知（反差最锋利，完播率高）

| 选题 | 核心反差 | 数据源 |
|---|---|---|
| 短视频的危害 | 只是消遣 → 正在重塑奖赏回路 | 神经科学期刊、平台使用时长统计 |
| 信息茧房的危害 | 看到更多 → 其实看到更少 | 算法推荐研究、皮尤研究中心调查 |
| 多任务处理的危害 | 同时做更多 → 效率反而腰斩 | 认知心理学任务切换实验 |
| 拖延的代价 | 只是晚点做 → 代价在复利 | 心理学纵向研究 |

### C. 财务 / 法律（实用性强，收藏率高）

| 选题 | 核心反差 | 数据源 |
|---|---|---|
| 婚姻的代价 | 领证就绑在一起 → 有几笔账是分开算的 | 《民法典》、民政部统计公报、裁判文书统计 |
| 社保断缴的后果 | 断了再补上就行 → 医保次月就停 | 各地人社局公开政策 |
| 信用卡分期的代价 | 免息 → 实际年化远超你以为 | 银行公开费率、央行金融消费报告 |

### D. 生活 / 环境

| 选题 | 核心反差 | 数据源 |
|---|---|---|
| 噪音的危害 | 只是吵 → 心血管风险升高 | WHO 环境噪音指南 |
| 长期喝含糖饮料的代价 | 解渴 → 果糖代谢路径完全不同 | 营养学与内分泌学研究 |
| 空调房待久的后果 | 舒服 → 呼吸道黏膜防线在失守 | 呼吸科临床研究 |

## 数据源优先级（找不到权威数据就别做）

按可信度排序，优先用靠前的：

1. **国际权威机构**：WHO、IARC、《柳叶刀》、Nature / Science 系列、CDC、NIH
2. **国内官方**：国家卫健委、民政部、国家统计局、中国疾控中心，以及各部委年度公报
3. **中国权威学会**：中国睡眠研究会、中国营养学会、中华医学会各分会
4. **同行评议论文 + 高校研究团队成果**
5. **可信媒体对论文的转述** —— 但必须回溯到原始论文，别直接抄媒体标题

**绝对不要用**：自媒体截图、没有出处的"研究表明"、AI 生成的数字、论坛帖子。

## 红线：这些选题不能碰

- **对国家政策的负面评价** —— 如「XX 制度的危害」「XX 政策不公平」。这类选题无论数据多客观都会被判违规。
  → **可转化**：把"制度有问题"改成"个人如何应对"。
  例：社保 → 「社保断缴的后果」「跨省换工作社保怎么转」。
- **医疗诊断与治疗建议** —— 可以说"研究显示 X 与 Y 相关"，不能说"你有 X 就该吃 Y"。
- **涉及具体个人的隐私、名誉** —— 不点名、不放真实姓名、不放可识别信息。
- **性别 / 地域 / 职业的对立性话题** —— 流量高但风险极高，不做。
- **诱导投资、荐股、医疗功效承诺** —— 直接违规。

## 开做前的一条自检

问自己：**如果这个标题被平台审核员看到，他会不会觉得"这是在制造焦虑或对立"？**

如果会，就换角度——把"危害"改成"后果 / 代价"，把"制度问题"改成"个人应对"，
把"不能做 X"改成"做 X 之前该知道什么"。同一份数据，换个说法就能过。
